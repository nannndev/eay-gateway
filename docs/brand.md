## Cara Ganti Logo Aktif

Semua file vektor tersimpan di `docs/public/logos/`. Untuk mengganti logo utama, cukup salin salah satu file tersebut ke `docs/public/logo.svg`:

```sh
# Contoh memilih Option 3 (Obsidian Gate)
cp docs/public/logos/option-3-portal.svg docs/public/logo.svg
```
